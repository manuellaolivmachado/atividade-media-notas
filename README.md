# 📚 Atividade - Média e Notas

Atividade desenvolvida em JavaScript para calcular a média de um aluno e classificar seu desempenho.

## 💻 Tecnologias

- JavaScript

## ✨ Funcionalidades

- Solicitação do nome do aluno
- Validação do nome
- Entrada de três notas
- Validação das notas
- Cálculo da média
- Classificação do desempenho em A, B, C ou D
- Exibição do resultado no console

## 📖 Sobre o projeto

Este projeto foi desenvolvido como uma atividade de estudo para praticar conceitos básicos de JavaScript e lógica de programação.

O programa recebe o nome do aluno e três notas, calcula a média e apresenta uma classificação de acordo com o resultado.
